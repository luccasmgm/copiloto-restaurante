Sobre o projeto

Problema. Donos de restaurante gastam horas por semana montando planilhas e ainda reagem tarde a cancelamentos e atrasos.

Solução. Um pipeline único: dados de pedidos, KPIs em dashboard, regras de alerta, relatório diário gerado automaticamente e um agente que escolhe a ferramenta certa para responder cada pergunta (o rastro de chamadas aparece em cada resposta).

Impacto estimado. Estimativa baseada em 15 min de montagem manual por dia mais 30 min por semana de análise.

  • Stack: HTML, CSS e JavaScript puro, sem dependências, publicado como página única.
  • Próximo passo: trocar o roteador de intenções por um LLM com tool calling usando as mesmas funções.
